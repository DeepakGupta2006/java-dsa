# Java DSA

A structured collection of Data Structures & Algorithms problems and notes, implemented in Java, organized by topic.

## Structure

| Folder | Topic |
|---|---|
| 00_Loops | For/while loop basics, pattern printing |
| 01_Arrays | Array manipulation, two-pointers, prefix sums |
| 02_Strings | String processing, pattern matching |
| 03_LinkedList | Singly/Doubly linked list operations |
| 04_Stacks_Queues | Stack & Queue based problems |
| 05_Recursion | Recursion & divide-and-conquer |
| 06_Sorting | Sorting algorithms (bubble, merge, quick, etc.) |
| 07_Searching | Binary search & variants |
| 08_Trees | Binary trees, BST, traversals |
| 09_Graphs | Graph representations, BFS/DFS, shortest paths |
| 10_DynamicProgramming | DP problems (1D, 2D, knapsack, etc.) |
| 11_Backtracking | Backtracking problems |
| 12_Greedy | Greedy algorithm problems |

## How to run

Each problem is a standalone `.java` file with a `main` method.

```bash
javac path/to/File.java
java -cp path/to Filename
```

## Conventions
- One class/problem per file, named after the problem (e.g. `NextPermutation.java`).
- Each file has a short comment block describing the problem statement, approach, and time/space complexity.
